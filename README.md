# 🎵 Virtual Xylophone

Интерактивный музыкальный инструмент, реализованный на чистом JavaScript.  
Позволяет играть ноты в реальном времени и воспроизводить созданные пользователем музыкальные последовательности.

## О проекте

**Виртуальный ксилофон** — адаптивное приложение, полностью генерируемое через JavaScript (`createElement`), без статической разметки.  
Каждая клавиша имеет уникальный звук, реагирует на клики и нажатия клавиш клавиатуры, а также допускает переназначение горячих клавиш.
Для проигрывания готовых аудиофайлов используется Web Audio API

## Реализованный функционал

- **Адаптивный интерфейс**: Desktop ≥1440px, Tablet ≥768px, Mobile ≥360px  
- **Интерактивные клавиши** с тремя состояниями (default, hover, active), воспроизведение готовых звуков через Web Audio API  
- **Управление клавишами**: возможность переназначения через input, защита от конфликтов  
- **Автоматическое воспроизведение**: ввод музыкальной последовательности с ограничением длины и последовательным проигрыванием звуков 
- **Поддержка клавиатуры**: работа с любой раскладкой и Caps Lock  
- **Минималистичный UI** с визуальной подсветкой активных элементов  
- **Форматирование и стиль** соблюдаются при помощи **ESLint** и **Prettier**
