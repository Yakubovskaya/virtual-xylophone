# 🎵 Virtual Xylophone

An interactive musical instrument built with JavaScript.  
Allows playing notes in real time and reproducing user-created musical sequences.

## About the Project

**Virtual Xylophone** — a fully responsive application, entirely generated with JavaScript (`createElement`), without static HTML markup.  
Each key has a unique sound, responds to mouse clicks and keyboard presses, and supports custom key reassignment.  
Playback of pre-recorded audio files is handled via **Web Audio API**.

## Features

- **Responsive interface**: Desktop ≥1440px, Tablet ≥768px, Mobile ≥360px  
- **Interactive keys** with three states (**default**, **hover**, **active**), playback of pre-recorded sounds via **Web Audio API**  
- **Key management**: reassignment via input with conflict prevention  
- **Automatic playback**: input of musical sequences with length limitation and sequential sound playback  
- **Keyboard support**: works with any layout and Caps Lock  
- **Minimalist UI** with visual feedback on active elements  
- **Code style and formatting** enforced with **ESLint** and **Prettier**
